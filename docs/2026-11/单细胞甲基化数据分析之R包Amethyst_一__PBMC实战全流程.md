<div><section data-tool="mdnice编辑器" data-website="https://www.mdnice.com" data-pm-slice="0 0 []"><h3 data-tool="mdnice编辑器"><span><span leaf="">导语</span></span></h3><p data-tool="mdnice编辑器"><span leaf="">单细胞转录组、单细胞 ATAC 大家应该都很熟悉了，相比之下，单细胞 DNA 甲基化（single-cell DNA methylation）还算是一个比较“小众”的模态。但 DNA 甲基化有它独特的优势：它是一种相对稳定的表观遗传标记，记录着细胞的身份和发育历史，不像 mRNA 那样会随细胞状态快速波动。近几年，随着 snmC-seq、sci-MET 等单细胞甲基化测序技术的发展，以及 ScaleBio 等商业化试剂盒的推出，单细胞甲基化数据越来越容易拿到，脑、血液、肿瘤等领域都已经陆续出现了单细胞甲基化图谱。</span></p><p data-tool="mdnice编辑器"><span leaf="">不过，单细胞甲基化数据的分析思路和单细胞转录组很不一样：</span></p><ul><li><section><strong><span leaf="">数据极其稀疏</span></strong><span leaf="">：每个细胞只能测到基因组中一小部分 CpG 位点，而且在单个细胞里，一个位点基本只有“甲基化 / 未甲基化”两种状态，没法像基因表达量那样直接拿来当特征；</span></section></li><li><section><strong><span leaf="">特征需要自己构建</span></strong><span leaf="">：通常要先把位点汇总到基因组窗口、基因或调控区域上，得到一张“区域 × 细胞”的甲基化矩阵，再去做降维聚类；</span></section></li><li><section><strong><span leaf="">技术偏倚明显</span></strong><span leaf="">：每个细胞测到多少个胞嘧啶（覆盖度）差异很大，覆盖度本身就很容易驱动聚类；</span></section></li><li><section><strong><span leaf="">解读方向“反着来”</span></strong><span leaf="">：启动子、增强子等调控区域的</span><strong><span leaf="">低甲基化</span></strong><span leaf="">通常对应基因激活，所以看 marker 时要找“低”而不是“高”。</span></section></li></ul><p data-tool="mdnice编辑器"><strong><span leaf="">目前常见的单细胞甲基化分析工具大致有这几个：</span></strong></p><section leaf="">GitHub：https://github.com/lrylaarsdam/amethyst</span></p><h3 data-tool="mdnice编辑器"><span><span leaf="">一. 单细胞甲基化快速扫盲</span></span></h3><p data-tool="mdnice编辑器"><strong><span leaf="">篇幅有限，先把后文会反复出现的几个关键词过一遍：</span></strong></p><section data-tool="mdnice编辑器"><table><thead><tr><th><strong><span leaf="">关键词</span></strong></th><th><strong><span leaf="">核心意思</span></strong></th></tr></thead><tbody><tr><td><section><span leaf="">亚硫酸氢盐转化（bisulfite conversion）</span></section></td><td><section><span leaf="">把未甲基化的 C 转成 U（测序读作 T），甲基化的 C 保持不变；比对后某个 C 位点读到 C 就是甲基化、读到 T 就是未甲基化</span></section></td></tr><tr><td><section><span leaf="">c / t 计数</span></section></td><td><section><span leaf="">h5 文件中每个位点的两列：c = 甲基化观测数，t = 未甲基化观测数；单细胞里绝大多数位点只有 1 条读数</span></section></td></tr><tr><td><section><span leaf="">mCG</span></section></td><td><section><span leaf="">CpG 二核苷酸上的胞嘧啶甲基化，哺乳动物中最主要的甲基化形式，所有细胞都有，大部分 CpG 处于甲基化状态</span></section></td></tr><tr><td><section><span leaf="">mCH</span></section></td><td><section><span leaf="">非 CpG 位点（H = A / C / T）的甲基化，以 mCA 为主；在神经元中大量积累，在大多数其他细胞中很低（&lt; leaf="">覆盖度（cov / cg_cov）</span></section></td><td><section><span leaf="">每个细胞测到的胞嘧啶位点数，是最重要的 QC 指标，也是最常见的技术偏倚来源</span></section></td></tr><tr><td><section><span leaf="">低甲基化 / 高甲基化（hypo / hyper）</span></section></td><td><section><span leaf="">启动子、增强子等调控区的低甲基化通常对应基因激活；基因体 mCG 与表达的关系更复杂，在不少体系里是正相关，别和启动子混在一起</span></section></td></tr><tr><td><section><span leaf="">VMR（variably methylated region）</span></section></td><td><section><span leaf="">可变甲基化区域，即在细胞间变化大的区域，可以理解为“甲基化版的高变基因”</span></section></td></tr><tr><td><section><span leaf="">DMR（differentially methylated region）</span></section></td><td><section><span leaf="">差异甲基化区域，即组间甲基化显著不同的区域，相当于“甲基化版的差异基因”</span></section></td></tr><tr><td><section><span leaf="">伪 bulk（pseudobulk）</span></section></td><td><section><span leaf="">把同一群的细胞合并起来计算，用来克服单细胞数据的稀疏性</span></section></td></tr></tbody></table></section><p data-tool="mdnice编辑器"><strong><span leaf="">为什么 PBMC 教程只算 mCG？</span></strong></p><ul><li><section><strong><span leaf="">mCG</span></strong><span leaf=""> 是所有细胞都有的“默认”甲基化；PBMC 这类免疫细胞几乎没有 mCH，所以教程只用 mCG。</span></section></li><li><section><strong><span leaf="">mCH 是神经元的特征</span></strong><span leaf="">：神经元是有丝分裂后（post-mitotic）细胞，DNMT3A 会长期在基因体上沉积 mCH，并且 mCH 和基因表达负相关。所以脑组织的单细胞甲基化图谱主要依靠</span><strong><span leaf="">基因体 mCH</span></strong><span leaf=""> 区分神经元亚型，它比 mCG 更有分辨力。</span></section></li><li><section><strong><span leaf="">具有“神经样”特征的肿瘤会不会也有高 mCH？</span></strong><span leaf=""> 以神经内分泌前列腺癌（NEPC）为例，我的理解是要分清“神经样的转录身份”和“神经元式的 mCH 积累”这两件事：mCH 主要靠 de novo 沉积，不像 mCG 那样在 DNA 复制时被 DNMT1 维持，细胞持续分裂会把它稀释掉。因此增殖的肿瘤细胞即使表达神经相关基因，也不太可能积累出神经元那样的高 mCH。实际分析时建议</span><strong><span leaf="">以 mCG 为主</span></strong><span leaf="">，再顺手比较一下各群的全局 mCH（metadata 里的 mch_pct），看看 NE 样细胞群有没有升高。</span></section></li></ul><p data-tool="mdnice编辑器"><strong><span leaf="">⚠️ 需要注意的是：看到某些细胞 mCH 偏高时，先别急着当成生物学信号。亚硫酸氢盐转化不完全时，未转化的 C 会“冒充”甲基化，最直接的表现就是 mCH
