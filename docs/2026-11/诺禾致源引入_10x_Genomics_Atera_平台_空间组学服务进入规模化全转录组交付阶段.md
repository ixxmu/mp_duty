leaf=""><span textstyle="">Atera 是 10x Genomics 于 2026 年正式推出的新一代原位空间生物学平台，被公司定义为空间组学领域的一次代际升级。其核心能力可概括为三个维度，每一项都直接回应现有空间工作流中的关键瓶颈：</span></span></p><section data-role="list" data-pm-slice="0 0 全转录组覆盖，使panel预设不再构成发现范围的前置约束</span></span></p></section><p><span leaf=""><span textstyle="">Atera WTA模式的预设计panel覆盖18,028个蛋白编码基因，并可额外叠加最多1,000个自定义靶标。对于肿瘤异质性全景解析、罕见细胞状态发现、未知机制探索等以“不预设答案”为前提的研究，研究者无需在实验前被靶向panel的基因列表划定探索边界。</span></span></p><section data-role="list" data-pm-slice="0 0 []"><p><span 单细胞级灵敏度与亚细胞定位精度并存</span></span></p></section><p><span leaf=""><span textstyle="">Atera沿用Xenium原位成像架构，像素约0.2 μm，转录本XY定位精度20 nm、Z轴&lt;150 nm，结合多模态细胞分割，可在不规则组织中实现单细胞乃至亚细胞级转录本归位。根据10x Genomics公开的FFPE预览数据，Atera WTA在单细胞水平捕获的中位转录本数约为Xenium v1(280基因panel）的8.8倍(乳腺癌)和15.5倍(宫颈癌)，其单细胞转录本捕获深度已接近单细胞Flex水平。对免疫微环境、组织边界过渡态、神经元亚区等精细问题，这一定位精度与单细胞级检出深度提供的是可支撑机制推断的单分子空间证据。</span></span></p><section data-role="list" data-pm-slice="0 0 []"><p><span leaf="" data-pm-slice='1 1 ["para",{"tagName":"p","attributes":{},"namespaceURI":"http://www.w3.org/1999/xhtml","data-layout-id":null}]'><span Genomics公布的理论通量）。同时兼容FFPE与新鲜冰冻样本及标准载玻片，样本制备与组织放置流程显著简化。对于需要数十例乃至上百例样本的队列型空间研究，这一通量水平将空间组学从“精选样本的验证工具”推向“大队列发现的常规选项”。</span></span></p><section data-tools="135编辑器" data-id="169781" data-pm-slice="0 0
