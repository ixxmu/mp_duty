<div><section data-tool="mdnice编辑器" data-website="https://www.mdnice.com" data-pm-slice="0 0 []"><h2 data-cacheurl="" data-remoteid="" data-tool="mdnice编辑器"><span><span leaf="">1. 为什么要做组成差异分析</span></span></h2><p data-tool="mdnice编辑器"><span leaf="">单细胞实验通常只从每个样本中捕获一部分细胞。不同样本测到的总细胞数受上机量、捕获效率和质控等因素影响，因此不能直接把“测到多少个细胞”当成组织中的绝对细胞数量。</span></p><p data-tool="mdnice编辑器"><span leaf="">因此，分析对象应是每个样本内部各细胞类型的相对丰度，而不是不同样本之间未经校正的细胞总数。</span></p><p data-tool="mdnice编辑器"><span leaf="">组成数据有一个重要约束：同一样本中所有细胞类型的比例加起来必然等于 1。假设健康组织中 A、B、C 各有 2,000 个细胞；患病后只有 A 增加到 4,000 个，B 和 C 的绝对数量都没有变化：</span></p><ul><li><section><span leaf="">健康：A、B、C 各占约 33%。</span></section></li><li><section><span leaf="">患病：A 占 50%，B 和 C 各占 25%。</span></section></li></ul><p data-tool="mdnice编辑器"><span leaf="">如果只比较比例，B 和 C 会呈现下降，尽管它们的绝对数量并未改变。这种表观下降由组成数据的总和约束产生，不能作为绝对耗竭的证据。因此，统计模型需要联合考虑所有细胞群，或明确一个相对稳定的参照。</span></p><p data-tool="mdnice编辑器"><span leaf="">那么组成差异分析这次介绍两条路线：</span></p><ul><li><section><span leaf="">已有可信的细胞类型或状态标签：用 </span><strong><span leaf="">scCODA</span></strong><span leaf="">。</span></section></li><li><section><span leaf="">标签之间还有明确的树状层级：用 </span><strong><span leaf="">tascCODA</span></strong><span leaf="">。</span></section></li></ul><h2 data-cacheurl="" data-remoteid="" data-tool="mdnice编辑器"><span><span
