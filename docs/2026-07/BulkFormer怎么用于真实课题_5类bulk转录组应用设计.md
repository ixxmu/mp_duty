应用场景。每个场景都给出研究问题、数据、分析路线、关键对照和验证方式，方便直接改造成课题方案。</span></p><section nodeleaf=""><img data-aistatus="1" data-imgfileid="100015293" data-ratio="0.4349680170575693" data-s="300,640" leaf=""><br></span></p><h2><span leaf="">一、先确定 BulkFormer 在课题中的角色</span></h2><p><span leaf="">BulkFormer 最适合承担三类角色。</span></p><p><strong><span leaf="">角色 1：冻结的特征提取器</span></strong></p><p><span leaf="">不修改预训练参数，只提取样本 embedding，再训练 Logistic regression、XGBoost、Cox 或神经网络。优点是稳定、计算量较小，适合样本量有限的临床队列。</span></p><p><strong><span leaf="">角色 2：表达补全模型</span></strong></p><p><span leaf="">对缺失基因或不同平台共有基因不足的问题进行预测。但补全结果必须与真实观测、随机 mask 和外部数据进行对照。</span></p><p><strong><span leaf="">角色 3：可微调的预训练骨干</span></strong></p><p><span leaf="">在较大且标签可靠的队列上微调模型。潜在性能更高，但更容易过拟合，也更依赖显存、训练策略和严格的数据拆分。</span></p><p><span leaf="">对于大多数首次使用者，建议从“冻结 embedding 加简单模型”开始。只有在基线结果明确、样本量足够时，再考虑微调。</span></p><h2><span leaf="">二、场景一：跨队列疾病分型</span></h2><p><strong><span leaf="">研究问题</span></strong></p><p><span leaf="">BulkFormer 的样本 embedding 能否比原始表达、PCA 或传统 pathway score 更稳定地识别疾病亚型？</span></p><p><strong><span leaf="">适合数据</span></strong></p><ul><li><section><span leaf="">TCGA 某癌种及一个独立 GEO/ICGC 队列；</span></section></li><li><section><span leaf="">病例与对照 bulk RNA-seq；</span></section></li><li><section><span leaf="">具有明确分子亚型标签的队列；</span></section></li><li><section><span leaf="">每类最好至少有数十个样本，并保留完整临床信息。</span></section></li></ul><p><strong><span leaf="">推荐分析路线</span></strong></p><p><span leaf="">1. 统一 Ensembl ID 和 log-TPM 处理； 2. 分别构建原始高变基因、PCA、GSVA 和 BulkFormer embedding； 3. 在训练队列内部完成交叉验证和模型选择； 4. 锁定模型后，在完整外部队列验证； 5. 比较 weighted F1、macro F1、AUROC 和校准度； 6. 检查预测与组织来源、测序中心、性别、年龄和肿瘤纯度的关系。</span></p><p><strong><span leaf="">最低限度基线</span></strong></p><ul><li><section><span leaf="">原始表达加 Logistic regression；</span></section></li><li><section><span leaf="">PCA 加 Logistic regression；</span></section></li><li><section><span leaf="">pathway score 加分类器；</span></section></li><li><section><span leaf="">BulkFormer embedding 加同一个分类器。</span></section></li></ul><p><span leaf="">只有固定下游分类器，才能更清楚地判断增益是否来自 BulkFormer 表征，而不是更复杂的模型。</span></p><p><strong><span leaf="">关键验证</span></strong></p><p><span leaf="">训练和验证最好来自不同研究中心。若只在同一数据集中随机拆分，模型可能主要识别建库批次或队列特征。</span></p><p><span leaf="">【配图建议】这里画训练队列与外部验证队列完全分离的流程图，突出“预处理规则锁定后再打开验证集”。</span></p><h2><span leaf="">三、场景二：预后模型与风险分层</span></h2><p><strong><span leaf="">研究问题</span></strong></p><p><span leaf="">BulkFormer embedding 能否在临床变量之外提供独立预后信息，并在外部队列保持风险排序？</span></p><p><strong><span leaf="">适合数据</span></strong></p><ul><li><section><span leaf="">TCGA 生存队列；</span></section></li><li><section><span leaf="">带 OS、PFS、DFS 或治疗后随访的 bulk RNA-seq；</span></section></li><li><section><span leaf="">有年龄、分期、性别、治疗方案等协变量。</span></section></li></ul><p><strong><span leaf="">推荐设计</span></strong></p><p><span leaf="">先用冻结的 sample embedding，连接带正则化的 Cox 模型。不要一开始就把 600 多维 embedding 全部无约束放入样本量很小的 Cox 回归。</span></p><pre><code><span leaf="">BulkFormer embedding</span><span leaf=""><br></span><span leaf="">        ↓</span><span leaf=""><br></span><span leaf="">训练集内标准化与降维/正则化</span><span leaf=""><br></span><span leaf="">        ↓</span><span leaf=""><br></span><span leaf="">Elastic-net Cox 或 Random Survival Forest</span><span leaf=""><br></span><span leaf="">        ↓</span><span leaf=""><br></span><span leaf="">内部交叉验证确定超参数</span><span leaf=""><br></span><span leaf="">        ↓</span><span leaf=""><br></span><span leaf="">外部队列评估 C-index、time-dependent AUC 和 calibration</span></code></pre><p><strong><span leaf="">需要比较的模型</span></strong></p><ul><li><section><span leaf="">临床变量模型；</span></section></li><li><section><span leaf="">临床变量加传统 gene signature；</span></section></li><li><section><span leaf="">临床变量加 PCA；</span></section></li><li><section><span leaf="">临床变量加 BulkFormer embedding。</span></section></li></ul><p><strong><span leaf="">关键验证</span></strong></p><p><span leaf="">风险分数的阈值只能在训练集确定，不能在验证集中重新寻找最佳 cut-off。还应检查比例风险假设，并报告不同随访时间点的性能，而不是只给一张 Kaplan-Meier 曲线。</span></p><p><strong><span leaf="">可扩展问题</span></strong></p><p><span leaf="">比较全基因 mean pooling 与癌症相关基因集 pooling，观察更聚焦的 gene set 是否能够提升稳定性和可解释性。</span></p><h2><span leaf="">四、场景三：缺失基因补全与历史队列整合</span></h2><p><strong><span leaf="">研究问题</span></strong></p><p><span leaf="">能否利用 BulkFormer 补全不同 panel 或历史测序数据中缺失的基因，使多个队列进入同一特征空间？</span></p><p><strong><span leaf="">适合数据</span></strong></p><ul><li><section><span leaf="">同时存在全转录组和靶向 panel 的配对样本；</span></section></li><li><section><span leaf="">不同平台具有部分重叠基因的历史队列；</span></section></li><li><section><span leaf="">因过滤或测序深度导致部分基因缺失的 bulk RNA-seq。</span></section></li></ul><p><strong><span leaf="">推荐验证方案</span></strong></p><p><span leaf="">1. 从完整 bulk RNA-seq 中人为 mask 10%、20%、30% 基因； 2. 分别按随机基因、高低表达基因和特定 pathway 基因进行 mask； 3. 使用 BulkFormer 预测缺失表达； 4. 在被 mask 位置计算 Pearson、Spearman、MAE 和 pathway score 一致性； 5. 把补全后的矩阵用于一个预先定义的下游任务； 6. 在真实 panel 与全转录组配对样本上做外部验证。</span></p><p><strong><span leaf="">为什么不能只报告整体相关性</span></strong></p><p><span leaf="">高表达基因容易主导整体 PCC。更稳妥的做法是按表达水平、基因变异度和 pathway 分层评估，并单独报告真正缺失位置的误差。</span></p><p><strong><span leaf="">边界条件</span></strong></p><p><span leaf="">BulkFormer 当前是人类 bulk RNA-seq 模型。微阵列、L1000/LINCS、NanoString、空间转录组和小鼠数据都存在明显 domain shift，不能因为矩阵也是“基因乘样本”就直接当作同模态输入。</span></p><h2><span leaf="">五、场景四：药物反应预测</span></h2><p><strong><span leaf="">研究问题</span></strong></p><p><span leaf="">在药物处理前的细胞系 bulk RNA-seq 中，BulkFormer 表征能否改善 IC50/AUC 预测，并迁移到类器官或患者队列？</span></p><p><strong><span leaf="">适合数据</span></strong></p><ul><li><section><span leaf="">GDSC、CTRP、PRISM 等细胞系资源；</span></section></li><li><section><span leaf="">药物处理前的 baseline bulk RNA-seq；</span></section></li><li><section><span leaf="">连续药敏指标及药物靶点信息；</span></section></li><li><section><span leaf="">最好有独立平台或类器官队列验证。</span></section></li></ul><p><strong><span leaf="">推荐建模路线</span></strong></p><p><span leaf="">样本 embedding 表示细胞系状态，药物侧使用分子指纹、靶点或药物 embedding，两者拼接后预测药敏。</span></p><pre><code><span leaf="">细胞系 baseline RNA-seq → BulkFormer sample embedding</span><span leaf=""><br></span><span leaf="">药物 SMILES/靶点      → drug feature</span><span leaf=""><br></span><span leaf="">两类特征拼接          → regression model</span><span leaf=""><br></span><span leaf="">输出                  → IC50 或 AUC</span></code></pre><p><strong><span leaf="">数据拆分是核心</span></strong></p><p><span leaf="">随机拆分 cell line-drug pair 往往会让同一细胞系或同一药物同时出现在训练和测试中，得到过于乐观的性能。至少应同时报告以下设置：</span></p><ul><li><section><span leaf="">未见过的 cell line；</span></section></li><li><section><span leaf="">未见过的 drug；</span></section></li><li><section><span leaf="">未见过的 cell line 和 drug 组合；</span></section></li><li><section><span leaf="">跨数据集外部验证。</span></section></li></ul><p><strong><span leaf="">重要更新</span></strong></p><p><span leaf="">仓库已经删除旧版 compound perturbation prediction benchmark。原因是 LINCS 转录谱并非标准 bulk RNA-seq，与预训练模态和基因覆盖不一致。这里讨论的是</span><strong><span leaf="">处理前 bulk RNA-seq 对药敏表型的预测</span></strong><span leaf="">，不是用旧版 LINCS 任务复现扰动后表达变化。</span></p><h2><span leaf="">六、场景五：基因依赖和治疗靶点优先级</span></h2><p><strong><span leaf="">研究问题</span></strong></p><p><span leaf="">BulkFormer 的样本特异基因 embedding 能否帮助预测 CRISPR gene dependency，并筛选特定癌症背景下的候选依赖基因？</span></p><p><strong><span leaf="">适合数据</span></strong></p><ul><li><section><span leaf="">DepMap cell line bulk RNA-seq；</span></section></li><li><section><span leaf="">Chronos/CRISPR gene effect；</span></section></li><li><section><span leaf="">突变、拷贝数、组织来源等多组学信息；</span></section></li><li><section><span leaf="">独立 CRISPR screen 或实验验证集。</span></section></li></ul><p><strong><span leaf="">两种建模策略</span></strong></p><p><strong><span leaf="">策略 A：样本级建模</span></strong></p><p><span leaf="">使用 sample embedding 加基因身份特征，预测某细胞系对某基因的依赖分数。优点是实现简单，适合先做大规模基线。</span></p><p><strong><span leaf="">策略 B：基因级建模</span></strong></p><p><span leaf="">使用每个样本中对应基因的 contextual embedding，并结合 ESM2、突变和拷贝数特征。优点是更贴近“同一基因在不同细胞状态中的依赖差异”，但输出体积和模型复杂度更高。</span></p><p><strong><span leaf="">关键对照</span></strong></p><ul><li><section><span leaf="">仅表达量；</span></section></li><li><section><span leaf="">表达量加突变/CNV；</span></section></li><li><section><span leaf="">BulkFormer embedding；</span></section></li><li><section><span leaf="">BulkFormer embedding 加多组学特征。</span></section></li></ul><p><strong><span leaf="">实验验证路线</span></strong></p><p><span leaf="">候选靶点应优先满足：模型预测稳定、多个队列一致、正常组织表达可接受、与已知机制相符，并在至少两种细胞系中通过 CRISPR/siRNA 和 rescue 实验验证。</span></p><p><span leaf="">【配图建议】这里画“计算优先级 → 多队列复现 → 正常组织安全窗口 → CRISPR 验证”的漏斗图。</span></p><h2><span leaf="">七、一个可复用的项目目录</span></h2><pre><code><span leaf="">bulkformer_project/</span><span leaf=""><br></span><span leaf="">  data_raw/</span><span leaf=""><br></span><span leaf="">  data_processed/</span><span leaf=""><br></span><span leaf="">  metadata/</span><span leaf=""><br></span><span leaf="">  resources_bulkformer/</span><span leaf=""><br></span><span leaf="">  embeddings/</span><span leaf=""><br></span><span leaf="">  models/</span><span leaf=""><br></span><span leaf="">  external_validation/</span><span leaf=""><br></span><span leaf="">  figures/</span><span leaf=""><br></span><span leaf="">  scripts/</span><span leaf=""><br></span><span leaf="">    01_prepare_counts.py</span><span leaf=""><br></span><span leaf="">    02_align_gene_vocab.py</span><span leaf=""><br></span><span leaf=""> leaf=""><br></span><span leaf="">    06_interpretation.py</span></code></pre><p><span leaf="">建议把预处理参数、基因词表版本、模型权重版本、缺失比例和样本顺序一并写入 manifest。这样跨队列更新时，能快速判断差异来自数据还是代码。</span></p><h2><span leaf="">八、结果解释和避坑清单</span></h2><p><strong><span leaf="">不要把 embedding 当成去卷积结果</span></strong></p><p><span leaf="">BulkFormer 表示的是混合组织表达上下文，细胞比例和细胞来源仍需单独估计。</span></p><p><strong><span leaf="">不要先合并全部队列再随机拆分</span></strong></p><p><span leaf="">这会把队列特异信号泄漏到测试集。外部验证应按数据集整体留出。</span></p><p><strong><span leaf="">不要只与复杂深度模型比较</span></strong></p><p><span leaf="">PCA、临床变量、pathway score 和简单线性模型是必要基线。</span></p><p><strong><span leaf="">不要忽略组织纯度和细胞组成</span></strong></p><p><span leaf="">肿瘤纯度、免疫浸润和基质比例可能同时影响 embedding 与临床结局，需要敏感性分析。</span></p><p><strong><span leaf="">不要把预测表达当成真实测量</span></strong></p><p><span leaf="">补全结果适合提出假设或统一特征空间，关键基因仍需原始测量或独立实验验证。</span></p><h2><span leaf="">九、小结</span></h2><p><span leaf="">BulkFormer 最值得做的课题，不是简单证明“换成基础模型后指标更高”，而是利用 bulk 模态预训练表征解决跨队列迁移、有限样本建模和上下文依赖等具体问题。</span></p><p><span leaf="">一个稳妥的起点是：选择一个标签清楚的训练队列和一个完全独立的验证队列，用冻结 sample embedding 加简单模型，与原始表达、PCA 和 pathway score 公平比较。确认增益后，再进入微调、基因级表征或多组学融合。</span></p><h2><span leaf="">参考资料</span></h2><p><span leaf="">1.
