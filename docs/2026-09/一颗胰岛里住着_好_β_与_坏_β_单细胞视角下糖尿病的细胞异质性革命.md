leaf="">科学问题：T2D 状态下 β 细胞不是整体等量受损，那有没有“功能亚群”？去分化（比如丢掉 MafA、Pdx1、Nkx6.1 这些 β 细胞标志，转而去表达多激素或者外分泌样程序）是渐进的，还是存在某个关键切换点？</span></section></li><li><section><span leaf="">技术：人胰岛用 snRNA-seq 比 scRNA-seq 更稳，因为解离带来的应激反应会大量丢失 β 细胞，单核更保真；再配上 SCENIC 推断转录因子调控网络，找出驱动功能状态的“主调控因子”。</span></section></li><li><section><span leaf="">分析：用轨迹推断（Slingshot / Monocle / PAGA）重建从健康成熟 β 到去分化状态的连续谱系；拿基因集评分来量化“β 身份度”。</span></section></li></ul><h3><span><span leaf="">方向二：胰岛内 β-α-δ 细胞通讯与 T2D</span></span></h3><ul><li><section><span leaf="">科学问题：胰岛这个“微型内分泌器官”的旁分泌网络（比如 β→α 的 GABA/Zn²⁺，α→β 的胰高血糖素样信号）在 T2D 里怎么失衡的？</span></section></li><li><section><span leaf="">技术：scRNA-seq 加上配体-受体推断（CellChat / NicheNet）；建议采用空间转录组（10x Visium、Slide-seq 等）来定位细胞通讯发生的微区。</span></section></li><li><section><span leaf="">分析：搭出细胞-细胞通讯网络，比较健康和 T2D 胰岛里“发送者-接收者”的强度变化；留意 δ 细胞（生长抑素）在稳态里扮演的“刹车”角色。</span></section></li></ul><h3><span><span leaf="">方向三：1 型糖尿病自身免疫浸润图谱</span></span></h3><ul><li><section><span 单细胞免疫组库（scVDJ-seq）；冻存临床样本可以用单核转录组，同时兼顾免疫细胞和实质细胞。</span></section></li><li><section><span leaf="">分析：联合降维分型，找出富集的 CD8⁺ 效应 T、巨噬细胞亚群；用 VDJ 追克隆扩增；空间组学把免疫细胞和 β 细胞的“接触前沿”定位出来。</span></section></li></ul><h2><span><span leaf="">技术路线建议</span></span></h2><ol><li><section><span leaf="">样本：健康对照、T2D、T1D（含自身抗体阳性前期）的人胰岛 / 胰十二指肠切除标本，分选或全组织单核。</span></section></li><li><section><span leaf="">测序：10x Genomics 3' 建库；T2D/T1D 加 scVDJ 和空间切片。</span></section></li><li><section><span leaf="">分析栈：质控 → 双细胞去除 → 批次校正（Harmony）→ 聚类 →
