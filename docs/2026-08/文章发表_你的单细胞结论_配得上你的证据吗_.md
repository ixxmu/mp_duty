文章发表：你的单细胞结论，配得上你的证据吗？ by Y叔 余光创
------
<div><section data-plugin="note-to-mp"><p><span leaf="">你可能见过这种操作：</span></p><ul><li><section><span leaf="">Seurat 流程跑完，UMAP 一出，图上点几坨，每坨标一个细胞类型，故事开写。</span></section></li><li><section><span leaf="">DEG 拉出来，GSEA 一富集，"XX 通路显著激活"，下一段就变成"提示 XX 通路驱动 YY 进程"。</span></section></li></ul><p><span leaf="">这两步，是单细胞文章里最常见的两个跳步。跑流程的人越来越多，翻车的地方却越来越一致：不在代码，在逻辑。</span></p><section nodeleaf=""><img leaf="">我们在 </span><em><span leaf="">Advanced Genetics</span></em><span leaf=""> 上发了一篇文章：From Cluster to Claim: Calibrating Interpretation in Single-Cell Transcriptomics，就是把这件事掰开说清楚：</span><strong><span leaf="">观察是观察，推断是推断，结论是结论，三者不能混着用。</span></strong></p><h2><span leaf="">跳步一：把聚类当细胞类型</span></h2><p><span leaf="">UMAP 上的一坨点，凭什么是"T cells"？再凭什么是"activated macrophages"？</span></p><p><span leaf="">cluster 本质上是算法按高维数据的密度切出来的数学结构，不是自然界预设好的抽屉。它可能反映谱系差异，也可能是细胞周期、解离应激、代谢波动，甚至是没去干净的批次效应。同一个 cluster，换个组织背景，指向的可能完全是另一样东西。</span></p><p><span leaf="">所以注释是推断，不是观察。"CD68、ITGAM 高，这坨是髓系"，有 marker 撑着，算合理推断；但接着写"激活的巨噬细胞"，就已经是功能解释了。巨噬细胞的极化本身就是个连续谱，"激活"这个标签，是对高维状态的一次粗暴压缩。</span></p><blockquote><p><span leaf="">聚类：我只是按相似度抱了个团，你们怎么就给我发身份证了？</span></p></blockquote><p><span leaf="">更别提"什么才算一个细胞类型"这个问题，领域里到现在也没吵明白。</span></p><h2><span leaf="">跳步二：把富集当机制</span></h2><p><span leaf="">第二条路更隐蔽，也更常见：</span></p><p><span leaf="">"XX 通路显著富集" → "XX 通路参与 YY" → "XX 通路介导 YY" → "XX 通路驱动 YY 肿瘤免疫逃逸"。</span></p><p><span leaf="">一条 GSEA 通路，怎么就一步步升官成"驱动"了？</span></p><p><span leaf="">DEG 只说明某个状态下转录本丰度有差异。从 mRNA 到蛋白，再到代谢通量、细胞行为，中间隔着翻译调控、翻译后修饰、空间区室好几层楼。而且单细胞是破坏性采样，数据天生是静态快照。没有扰动实验——时序建模也好、CRISPR screen 也好——光靠静态表达的相关性，"驱动""介导"这两个词是扛不住的。</span></p><p><strong><span leaf="">分子相关，不是功能因果。</span></strong></p><p><span leaf="">富集分析本身的坑，<a target="_blank" href="https://mp.weixin.qq.com/s?__biz=MzI5NjUyNzkxMg==&amp;mid=2247484529&amp;idx=1&amp;sn=c82b902b9cf56d3ee3e7c5a60f828846&amp;scene=21#wechat_redirect" textvalue="" linktype="text" data-linktype="2">我以前写过</a>，那里说的是统计层面怎么避坑；这里说的是另一件事：就算统计做得再干净，富集结果也只是相关性证据，不是机制。</span></p><h2><span leaf="">观察、推断、结论，分三层</span></h2><p><span leaf="">文章给了一个简单的框架：Observation → Inference → Claim。</span></p><ul><li><section><strong><span leaf="">观察层</span></strong><span leaf="">：UMAP 拓扑、DEG 列表、富集分数。回答"数据说了什么"，客观、可重复，不含生物学解释。</span></section></li><li><section><strong><span leaf="">推断层</span></strong><span leaf="">：拿 marker 和先验知识，给数据一个暂定身份。本质是溯因推理——在现有证据里挑一个最合理的解释，天生是概率性的、看上下文的。</span></section></li><li><section><strong><span leaf="">结论层</span></strong><span leaf="">：写进标题和摘要的那种话，"XX 介导 YY""XX 是 ZZ 所必需的"。这是从具体数据往普适规律的跳跃。</span></section></li></ul><p><span leaf="">三层之间各有一道"推理空隙"，翻车全发生在跳空隙的时候。这两个跳步只是典型代表，不是坑的全部。</span></p><p><span leaf="">还有个新变量让这事更麻烦：LLM 下场了。喂一个 gene list，它能把碎片缝成一个逻辑自洽、文笔流畅的故事。以前逻辑链上有裂缝，审稿人瞪大眼还能看见；现在裂缝被叙事糊得丝滑平整，</span><strong><span leaf="">连作者自己都看不见了</span></strong><span leaf="">。统计证据不够，被好文笔遮住了。</span></p><section nodeleaf=""><img drives？行，拿扰动实验和正交验证来换。拿不出来，就退回 suggested。这不丢人，丢人的是结论住三楼，证据还在一楼排队。</span></p><h2><span leaf="">写在最后</span></h2><p><span leaf="">单细胞是个发现引擎，不是因果仲裁器。它擅长产生假设、发现新状态、刻画异质性，这些是长处；但它给出的是相关性证据，静态转录本撑不起强因果结论。</span></p><p><strong><span leaf="">观察的分辨率上去了，不等于结论的合法性自动跟着升级。</span></strong></p><p><span
