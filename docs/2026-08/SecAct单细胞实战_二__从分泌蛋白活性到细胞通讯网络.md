<div><section data-pm-slice="0 0 []"><span><span leaf="">代码实操教程</span></span></section><section><h2><span leaf="">写在前面</span></h2><p><span leaf="">单细胞通讯分析常见的误区，是把某细胞表达配体、另一细胞表达受体直接解释为功能通讯。SecAct 通过“来源细胞表达变化 + 受体细胞信号活性变化”筛选条件特异通讯，为单细胞结果增加了一层功能约束。</span></p><p><span leaf="">本文使用官方卵巢癌示例，完成细胞状态活性推断、原发与转移样本比较，以及 sender-protein-receiver 网络可视化。</span></p><section nodeleaf=""><img data-aistatus="1" leaf=""><br></span></p><h2><span leaf="">安装与环境</span></h2><p><span leaf="">建议 R 4.2 及以上，并准备 SecAct、Seurat 和可视化依赖。首次安装可直接使用 GitHub。</span></p><pre><code><span leaf="">install.packages(c("remotes", "Seurat", "patchwork"))</span><span leaf=""><br></span><span leaf="">remotes::install_github("data2intelligence/SecAct")</span><span leaf=""><br></span><span leaf="">library(SecAct)</span><span leaf=""><br></span><span leaf="">library(Seurat)</span></code></pre><p><span leaf="">活性推断包含岭回归和置换，数据较大时可按官方 accelerator 教程安装加速包。</span></p><h2><span leaf="">输入对象需要什么</span></h2><p><span leaf="">输入是 Seurat 对象。细胞状态分析至少需要一个细胞类型/状态列；条件特异通讯还需要一个分组列，并确保每个主要细胞类型在两组中都有足够细胞。</span></p><pre><code><span leaf="">obj &lt;- readRDS("OV_scRNAseq_Seurat.rds")</span><span leaf=""><br></span><span leaf="">table(obj$MyCellType, obj$Groups)</span><span leaf=""><br></span><span leaf="">DimPlot(obj, group.by = "MyCellType")</span><span leaf=""><br></span><span leaf="">DimPlot(obj, group.by = "Groups")</span></code></pre><h2><span leaf="">第一步：推断不同细胞状态的分泌蛋白活性</span></h2><p><span leaf="">如果关注 CD4 T 细胞 naive、central memory 和 Th1-like 状态，可使用细胞状态注释列进行推断。</span></p><pre><code><span leaf="">obj &lt;- SecAct.activity.inference.scRNAseq(</span><span leaf=""><br></span><span leaf="">  obj,</span><span leaf=""><br></span><span leaf="">  cellType_meta = "Annotation"</span><span leaf=""><br></span><span leaf="">)</span><span leaf=""><br></span><span leaf=""><br></span><span leaf="">act &lt;- obj@misc$SecAct_output$SecretedProteinActivity$zscore</span><span leaf=""><br></span><span leaf="">dim(act)</span><span leaf=""><br></span><span leaf="">act[1:6, 1:3]</span></code></pre><p><span leaf="">正值表示该分泌蛋白在对应细胞状态中的相对活性较高，负值表示相对较低。不要把 z score 解释成蛋白浓度。</span></p><h2><span leaf="">第二步：比较两种条件下的细胞通讯</span></h2><p><span leaf="">官方示例比较卵巢癌转移灶与原发灶。函数先计算各来源细胞中分泌蛋白表达变化，再计算各受体细胞中的同名分泌蛋白活性变化，最后连接两端。</span></p><pre><code><span leaf="">obj &lt;- SecAct.CCC.scRNAseq(</span><span leaf=""><br></span><span leaf="">  obj,</span><span leaf=""><br></span><span leaf="">  cellType_meta = "MyCellType",</span><span leaf=""><br></span><span leaf="">  condition_meta = "Groups",</span><span leaf=""><br></span><span leaf="">  conditionCase = "Metastatic",</span><span leaf=""><br></span><span leaf="">  conditionControl = "Primary"</span><span leaf=""><br></span><span leaf="">)</span><span leaf=""><br></span><span leaf=""><br></span><span leaf="">ccc &lt;- obj@misc$SecAct_output$SecretedProteinCCC</span><span leaf=""><br></span><span leaf="">head(ccc)</span></code></pre><p><span leaf="">结果中的每一行代表一个候选通讯事件：该分泌蛋白在 case 组的 sender 中表达升高，同时在 receiver 中活性增强。</span></p><section nodeleaf=""><img data-aistatus="1" data-imgfileid="100015389"
