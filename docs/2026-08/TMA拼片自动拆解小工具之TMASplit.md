TMA拼片自动拆解小工具之TMASplit by 生信菜鸟团
------
<div><section data-tool="mdnice编辑器" data-website="https://www.mdnice.com" data-pm-slice="0 0 []"><p data-tool="mdnice编辑器"><span leaf="">传统的 TMA（Tissue Microarray）在 IHC、mIF 等实验中大家已经非常熟悉了。通过一次染色，可以同时获取几十甚至上百个 tissue core 的蛋白表达信息，因此在大队列研究中非常高效。而在空间转录组领域，</span><strong><span leaf="">TMA 拼片测序其实也越来越常见</span></strong><span leaf="">。例如 Xenium、CosMx 等成像型空间转录组平台，都可以在一张 slide 上同时放置几十甚至上百个 core，从而显著提高单次实验的样本通量。最近推出的一些大面积空间转录组平台，例如 Atera，由于可测区域更大，同样非常适合进行 TMA 拼片测序。但 TMA 拼片测完之后，会马上遇到一个非常实际的问题：</span><strong><span leaf="">如何把一张 slide 上的几十甚至上百个 core 自动拆开？</span></strong></p><p data-tool="mdnice编辑器"><span leaf="">关于这个问题，我大概在一年前就做过一些探索。对于 CosMx 来说，TMA core 的拆解相对简单一些。CosMx 本身采用 FOV（Field of View）方式进行成像和测序，因此在很多情况下，可以直接利用 FOV 的空间信息辅助不同 core 的划分。但 Xenium 以及其他采用连续全局坐标体系的平台，处理起来会麻烦一些。</span></p><p data-tool="mdnice编辑器"><span leaf="">我之前主要尝试过两种方案。第一种方案是将 Xenium 数据生成 Loupe 文件，然后导入 Loupe Browser，通过人工选择不同区域的方式对各个 core 进行拆分。这种方法比较直观，但如果一张 slide 上有几十甚至上百个 core，纯人工操作的工作量会非常大。第二种方案，是我自己写了一个基于 </span><strong><span leaf="">DBSCAN</span></strong><span leaf=""> 的函数。思路其实很直接：TMA 上不同 core 之间通常存在明显的空间间隔，因此可以根据每个细胞的二维坐标和细胞之间的空间距离进行密度聚类，从而自动识别不同的 tissue core。这种方法确实可以解决大部分 core 的自动拆分问题，但在真实数据中，仍然存在两类非常典型的错误。</span></p><ul><li><section><p><span leaf="">第一类是 </span><strong><span leaf="">一个真实 core 被错误拆成多个 core</span></strong><span leaf="">。</span></p><p><span leaf="">例如某个 tissue core 中间存在组织脱落、坏死区域或者明显的低细胞密度区域，那么原本属于同一个 core 的细胞可能在空间上被分成两个不连续的区域。此时 DBSCAN 可能会把它们识别成两个独立 cluster。</span></p></section></li><li><section><p><span leaf="">第二类则刚好相反：</span><strong><span leaf="">两个独立 core 被错误识别成一个 core</span></strong><span leaf="">。</span></p><p><span leaf="">如果两个 core 本身距离比较近，或者两个 core 之间存在少量细胞、组织碎片形成“连接”，基于距离的聚类算法就可能把两个 core 合并成同一个 cluster。</span></p></section></li></ul><p data-tool="mdnice编辑器"><span leaf="">因此，DBSCAN 虽然能够显著减少人工拆分的工作量，但并不能完全替代人工审核。对于这些特殊情况，通常仍然需要进一步手动修正。</span></p><p data-tool="mdnice编辑器"><span leaf="">原本我一直想把自己之前的这套代码重新整理一下，打包成一个 R 包。不过今天在查资料的时候，我发现最近已经有一个叫 </span><strong><span leaf="">TMASplit</span></strong><span leaf=""> 的 R 包，做的事情和我的思路非常接近，甚至比我的思路更好。因此这篇文章就主要介绍一下 </span><strong><span leaf="">TMASplit</span></strong><span leaf="">，顺便看看它在真实 TMA 数据上的表现。不过在实际测试过程中，我也发现 TMASplit 当前的使用方式依赖 Seurat 对象。但从算法本身来看，</span><strong><span leaf="">TMA split 真正需要的信息其实非常简单——只需要每个细胞的二维空间坐标（cellid + X + Y）即可。</span></strong><span leaf="">而并不一定需要完整的 Seurat object。</span></p><h4 data-tool="mdnice编辑器"><span><span leaf="">1. R包TMASplit介绍</span></span></h4><p data-tool="mdnice编辑器"><span leaf="">TMASplit（https://github.com/UTS-Bioinformatics/TMASplit） 是一个用于</span><strong><span leaf="">空间转录组 TMA core 自动拆分</span></strong><span leaf="">的 R 包，目前官方已经测试过 </span><strong><span leaf="">10x Genomics Xenium 和 Visium</span></strong><span leaf=""> 数据。其基本思路是利用细胞或 spot 的空间坐标，首先通过 </span><strong><span leaf="">DBSCAN</span></strong><span leaf=""> 对不同 tissue core 进行聚类；对于部分相互接触、粘连或者形状不规则的 core，还提供了 </span><strong><span leaf="">DBSCAN + watershed</span></strong><span leaf=""> 的 hybrid 模式进行进一步拆分。</span></p><p data-tool="mdnice编辑器"><span leaf="">整体流程如下：</span></p><ul><li><section><span leaf="">Load the spatial dataset into a Seurat object.</span></section></li><li><section><span leaf="">Run TMASplit using standard DBSCAN mode.</span></section></li><li><section><span leaf="">Switch to hybrid mode if cores remain merged.</span></section></li><li><section><span leaf="">Review output plots and adjust parameters as needed.</span></section></li></ul><p data-tool="mdnice编辑器"><span leaf="">除了最基础的 DBSCAN 之外，TMASplit 还加入了一些针对 TMA 数据特点的处理，包括：</span></p><ul><li><section><span leaf="">DBSCAN 自动识别 TMA core</span></section></li><li><section><span leaf="">Watershed 辅助拆分相邻或部分粘连的 core</span></section></li><li><section><span leaf="">根据 circularity 过滤形状异常的 cluster</span></section></li><li><section><span leaf="">根据 core radius 对异常 core 进行校正</span></section></li><li><section><span leaf="">自动计算 core centroid</span></section></li><li><section><span leaf="">对最终 core 重新排序和编号</span></section></li></ul><p data-tool="mdnice编辑器"><span leaf="">因此从功能上来看，它已经比较接近一个完整的 TMA core split workflow。不过需要注意的是，目前 TMASplit 的输入主要围绕 </span><strong><span leaf="">Seurat object</span></strong><span leaf=""> 设计，因此在使用之前，需要先把 Xenium 或其他空间数据组织成对应的 Seurat 对象。</span></p><h4 data-tool="mdnice编辑器"><span><strong><span leaf="">2.
