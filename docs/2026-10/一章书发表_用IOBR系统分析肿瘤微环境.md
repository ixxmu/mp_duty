Built for high-throughput data—spanning both transcriptomic and genomic profiles—IOBR integrates six analytical modules, including transcriptomic data preprocessing, TME profiling, TME pattern identification, ligand–receptor interaction analysis, genome–TME interaction assessment, and visualization. In this chapter, we walk through a multi-omics workflow using example datasets, illustrating data preparation, distribution analyses, result interpretation, and graphical output. IOBR is open source and is available at https://github.com/IOBR/IOBR and a detailed GitBook (https://iobr.github.io/book/) offers a complete manual and analysis guide for each
