版本有额外要求。</span></p><pre><code><span leaf="">if (!requireNamespace("remotes", quietly = TRUE)) {</span><span leaf=""><br></span><span leaf="">  install.packages("remotes")</span><span leaf="">data(mOB)</span><span leaf=""><br></span><span leaf="">cd &lt;- mOB$counts</span><span leaf=""><br></span><span leaf="">pos &lt;- mOB$pos</span><span leaf=""><br></span><span leaf=""><br></span><span leaf="">dim(cd)</span><span leaf=""><br></span><span leaf="">head(pos)</span><span leaf=""><br></span></code></pre><p><span leaf="">这里 </span><code><span leaf="">cd</span></code><span leaf=""> 是</span><strong><span leaf="">基因 × spot</span></strong><span leaf=""> 的原始计数矩阵；</span><code><span leaf="">pos</span></code><span leaf=""> 存放空间位置，行名用于标识 spot。</span></p><p><span leaf="">请记住下面这张对应表，后面的转置就不会乱：</span></p><table><thead><tr><th><section><span leaf="">步骤</span></section></th><th><section><span leaf="">矩阵方向</span></section></th></tr></thead><tbody><tr><td><code><span leaf="">cleanCounts()</span></code></td><td><section><span leaf="">基因 × spot</span></section></td></tr><tr><td><code><span leaf="">restrictCorpus()</span></code></td><td><section><span leaf="">基因 × spot</span></section></td></tr><tr><td><code><span leaf="">fitLDA()</span></code></td><td><section><span leaf="">spot × 基因</span></section></td></tr></tbody></table><p><span leaf="">如果换成自己的数据，不能把 log-normalized 表达、SCT 残差或批次校正后的连续值当作原始计数。LDA 在这里使用的是非负整数计数。</span></p><h2><span leaf="">03｜质量控制与信息基因筛选</span></h2><pre><code><span leaf="">counts &lt;- cleanCounts(</span><span leaf=""><br></span><span leaf="">  counts = cd,</span><span leaf=""><br></span><span leaf="">  min.lib.size = 100,</span><span leaf=""><br></span><span leaf="">  min.reads = 1,</span><span leaf=""><br></span><span leaf="">  min.detected = 1,</span><span leaf=""><br></span><span leaf="">  verbose = TRUE</span><span leaf=""><br></span><span leaf="">)</span><span leaf=""><br></span><span leaf=""><br></span><span leaf="">corpus &lt;- restrictCorpus(</span><span leaf=""><br></span><span leaf="">  counts,</span><span leaf=""><br></span><span leaf="">  removeAbove = 1,</span><span leaf=""><br></span><span leaf="">  removeBelow = 0.05,</span><span leaf=""><br></span><span leaf="">  alpha = 0.05,</span><span leaf=""><br></span><span leaf="">  nTopOD = 1000,</span><span leaf=""><br></span><span leaf="">  plot = TRUE</span><span leaf=""><br></span><span leaf="">)</span><span leaf=""><br></span><span leaf=""><br></span><span leaf=""># 筛选基因后，个别 spot 可能变为全零，需再次检查</span><span leaf=""><br></span><span leaf="">corpus &lt;- corpus[, Matrix::colSums(corpus) &gt; 0, drop = FALSE]</span><span leaf=""><br></span><span leaf="">stopifnot(nrow(corpus) &gt; 1, ncol(corpus) &gt; 1)</span><span leaf=""><br></span></code></pre><p><span leaf="">这里有一个很值得纠正的细节：</span><strong><code><span leaf="">min.lib.size = 100</span></code><span leaf=""> 在当前实现中保留的是总 counts &gt;100 的 spot，不是“检测到超过 100 个基因”。</span></strong></p><p><code><span leaf="">removeBelow = 0.05</span></code><span leaf=""> 用于控制基因在 spot 中的检测频率；</span><code><span leaf="">alpha</span></code><span leaf=""> 在这里是筛选过度离散基因的显著性阈值，不是下一篇讨论的 LDA 模型 α。两个地方用了相同符号，含义不同。</span></p><p><span leaf="">这些阈值是示例起点。深度更低、基因面板更小或组织更复杂时，需要重新评估，不能照抄后就视为完成质量控制。</span></p><h2><span leaf="">04｜拟合多个 K：只在这里转置</span></h2><pre><code><span leaf="">ldas &lt;- fitLDA(</span><span leaf=""><br></span><span leaf="">  t(as.matrix(corpus)),</span><span leaf=""><br></span><span leaf="">  Ks = 2:9,</span><span leaf=""><br></span><span leaf="">  seed = 0,</span><span leaf=""><br></span><span leaf="">  ncores = 1,</span><span leaf=""><br></span><span leaf="">  plot = TRUE</span><span leaf=""><br></span><span leaf="">)</span><span leaf=""><br></span><span leaf=""><br></span><span leaf=""># 用训练困惑度最低的 K 作为初始候选</span><span leaf=""><br></span><span leaf="">k &lt;- as.integer(ldas$minOptK[1])</span><span leaf=""><br></span><span leaf="">optLDA &lt;- optimalModel(ldas, opt = k)</span><span leaf=""><br></span></code></pre><p><span leaf="">K 是希望模型学习的潜在组分数量。这里探索 2—9 只是为了演示，不表示嗅球“真正只有这些细胞类型”，也不要求与你在原论文中看到的完整分析设置相同。</span></p><p><span leaf="">当前实现的 perplexity 是训练集困惑度。最低值可以提供候选模型，但不足以确认生物学解释。下一篇会专门讨论怎么选 K。</span></p><p><span leaf="">数据规模较大时还要注意内存：拟合流程会涉及致密矩阵。一个双精度矩阵本身大约需要 </span><code><span leaf="">8 × spot数 × 基因数</span></code><span leaf=""> 字节，实际拟合还会使用更多内存。</span></p><h2><span leaf="">05｜提取结果：保留一份不做比例过滤的 θ</span></h2><pre><code><span leaf="">raw &lt;- getBetaTheta(optLDA, perc.filt = 0, betaScale = 1000)</span><span leaf=""><br></span><span leaf="">display &lt;- getBetaTheta(optLDA, perc.filt = 0.05, betaScale = 1000)</span><span leaf=""><br></span><span leaf=""><br></span><span leaf="">theta &lt;- raw$theta</span><span leaf=""><br></span><span leaf="">beta &lt;- raw$beta</span><span leaf=""><br></span><span leaf=""><br></span><span leaf="">dim(theta)</span><span leaf=""><br></span><span leaf="">dim(beta)</span><span leaf=""><br></span><span leaf="">range(rowSums(theta))</span><span leaf=""><br></span></code></pre><p><code><span leaf="">raw</span></code><span leaf=""> 用于保存未按小比例阈值过滤的结果，</span><code><span leaf="">display</span></code><span leaf=""> 用于简化展示。</span></p><p><span leaf="">为什么要分开？因为 </span><code><span leaf="">perc.filt = 0.05</span></code><span leaf=""> 会把低于阈值的组分置零，再重新归一化。它可能改变某些 spot 的比例，也可能删去全局为零的 topic 列。画图更清爽，不代表适合直接替代所有定量分析。</span></p><p><code><span leaf="">betaScale = 1000</span></code><span leaf=""> 只是把 β 的表达概率乘以 1000，便于查看。它不会恢复真实 UMI，也不能转换成单个细胞的绝对表达量。</span></p><h2><span leaf="">06｜空间展示：坐标必须按 spot 名称对齐</span></h2><pre><code><span leaf="">stopifnot(all(rownames(theta) %in% rownames(mOB$pos)))</span><span leaf=""><br></span><span leaf="">pos_use &lt;- mOB$pos[rownames(theta), c("x", "y"), drop = FALSE]</span><span leaf=""><br></span><span leaf="">stopifnot(identical(rownames(pos_use), rownames(theta)))</span><span leaf=""><br></span><span leaf=""><br></span><span leaf="">vizAllTopics(display$theta, pos_use, r = 0.4)</span><span leaf=""><br></span><span leaf=""><br></span><span leaf="">vizTopic(</span><span leaf=""><br></span><span leaf="">  theta = theta,</span><span leaf=""><br></span><span leaf="">  pos = pos_use,</span><span leaf=""><br></span><span leaf="">  topic = colnames(theta)[1],</span><span leaf=""><br></span><span leaf="">  plotTitle = "第一个潜在组分：未过滤比例"</span><span leaf=""><br></span><span leaf="">)</span><span leaf=""><br></span></code></pre><p><span leaf="">空间图错位，往往不是模型问题，而是坐标和表达矩阵排序不一致。不要只确认二者行数相同；要确认同一行确实属于同一个 spot。</span></p><p><code><span leaf="">r = 0.4</span></code><span leaf=""> 是示例坐标尺度下的饼图半径，换成像素坐标或其他空间单位时需要调整。若叠加组织图像，还要核实图像缩放和 y 轴方向。</span></p><h2><span leaf="">07｜换自己的数据，先过这四关</span></h2><p><span leaf="">替换 </span><code><span leaf="">cd</span></code><span leaf=""> 与 </span><code><span leaf="">pos</span></code><span leaf=""> 前，至少确认：计数为非负整数；基因与 spot 标识唯一；计数矩阵列名与坐标行名一致；过滤后仍有足够的非零 spot 和信息基因。</span></p><p><span leaf="">如果数据带有多张切片，先保留切片编号并检查批次。直接合并全部数据，不会自动消除技术差异。</span></p><p><span leaf="">成功得到图以后，下一步也不是立刻给每种颜色命名。先判断模型是否稳定、K 是否合理，再讨论这些组分可能代表什么。</span></p><p><span
